## 概念鞏固：用自己的話解釋

### Q1：W4 的核心主題「元件時間維度」是什麼意思？

一個 Vue 元件不只是靜態的 HTML 結構——它有**生命週期**：從建立（`setup` 執行）、掛載到 DOM（`onMounted`）、每次資料改變後更新（`onUpdated`），到最後從 DOM 移除（`onUnmounted`）。W4 的核心是學會在這條「時間軸」上的正確位置介入：初始化資料用 `onMounted`、清理副作用用 `onUnmounted`、用 `watchEffect` 響應資料變化並在 `onCleanup` 中取消舊操作。

把這些「時間行為」封裝進 Composable，就讓這段時間邏輯能在多個元件間複用——這是 W4 的終極目標。

### Q2：為什麼說 `v-model` 是「Props + Emits 的語法糖」？用程式碼舉例。

`v-model="text"` 在父元件使用時，Vue 實際上展開為兩件事：

```vue
<!-- 這兩個寫法等效 -->
<MyInput v-model="text" />
<MyInput :modelValue="text" @update:modelValue="val => text = val" />
```

子元件透過 `modelValue` prop 接收資料，透過 `emit('update:modelValue', newValue)` 通知父元件更新。「魔法」不存在，就是 Props（資料往下流）+ Emits（通知往上傳）的組合，只是 Vue 提供了更簡潔的語法。

### Q3：`withDefaults` 是用來解決什麼問題的？

當使用 TypeScript 型別宣告語法（`defineProps<{...}>()`）時，無法在型別定義裡指定預設值（型別定義是靜態的，預設值是執行期行為）。`withDefaults` 作為橋接工具，讓你既能用 TypeScript 精確定義型別，又能為可選 prop 指定預設值：

```ts
const props = withDefaults(defineProps<{
  label?: string
  count?: number
}>(), {
  label: '預設標籤',
  count: 0,
})
```
