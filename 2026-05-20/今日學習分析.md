## 概念鞏固：用自己的話解釋

### Q1：為什麼 `@input="onInput"` 的 `onInput` 要做 `event.target as HTMLInputElement`？

當 `@input` 觸發時，Vue 傳給你的是標準 DOM 的 `Event` 物件。`Event.target` 的型別是 `EventTarget`——這是所有可以發出事件的 DOM 元素的最廣泛基底型別，包含 `<div>`、`<button>`、`<input>` 等。

TypeScript 不知道你的 `@input` 是綁在 `<input>` 上的，所以它只給你 `EventTarget` 型別，而 `EventTarget` 沒有 `.value` 這個屬性（因為 `<div>` 沒有 `.value`）。

`as HTMLInputElement` 是告訴 TypeScript：「我知道這個 `target` 是一個 `<input>` 元素，請按照 `HTMLInputElement` 的型別定義讓我存取它的屬性」。這是正確的，因為我們確實把 `@input` 綁在 `<input>` 上。

### Q2：`defineModel` 版本的 `v-model="modelValue"` 為什麼不違反 Props Down 原則？

表面上看，`v-model="modelValue"` 像是「直接修改了一個值」，感覺違反了「子元件不能修改 props」。

但 `defineModel` 回傳的不是 props 裡的原始值——它是 Vue 內部建立的一個**代理 ref**。當你寫入 `modelValue.value = '新值'` 時，Vue 在底層執行的是 `emit('update:modelValue', '新值')`，仍然是透過 emit 通知父元件，父元件自己決定是否更新。

所以 `defineModel` 是「語法糖進化版」：讓你寫得像直接修改，但底層仍然遵循 Props Down 的資料流原則。

### Q3：什麼情況下應該選 `defineProps + defineEmits` 而不是 `defineModel`？

主要有三種情況：

1. **需要在 emit 前做驗證或轉換**：例如數字輸入欄位需要過濾非數字字元，`defineProps + defineEmits` 讓你在 `onInput` 中先過濾再 emit。`defineModel` 寫入時立即 emit，無法插入攔截邏輯。

2. **需要相容 Vue 3.3 以下**：`defineModel` 是 Vue 3.4 才穩定的 macro，舊專案無法使用。

3. **需要讓意圖更明顯**：對初次閱讀程式碼的人來說，`onInput → emit('update:modelValue')` 的流程比 `v-model="modelValue"` 更清楚地表達「這裡發生了元件通訊」。

## 今日知識地圖

```
CustomInput.vue 完整實作（W5 Day 2 成果）
│
├── 定義層
│   ├── interface Props { label, modelValue, placeholder?, disabled?, errorMessage? }
│   ├── withDefaults(defineProps<Props>(), { placeholder: '', disabled: false, errorMessage: '' })
│   └── defineEmits<{ 'update:modelValue': [value: string]; blur: [event: FocusEvent] }>()
│
├── 邏輯層
│   ├── onInput(event: Event)
│   │   ├── const target = event.target as HTMLInputElement  ← type narrowing
│   │   └── emit('update:modelValue', target.value)
│   └── onBlur(event: FocusEvent)
│       └── emit('blur', event)
│
├── 模板層
│   ├── <label>{{ props.label }}</label>
│   ├── <input :value="props.modelValue" :disabled="props.disabled" @input @blur />
│   └── <p v-if="props.errorMessage">{{ props.errorMessage }}</p>
│
├── 對照版（defineModel）
│   ├── const modelValue = defineModel<string>({ required: true })
│   ├── 其他 props 仍需 defineProps
│   └── <input v-model="modelValue" />  ← 可直接綁定，底層仍是 emit
│
└── 泛型預備（面向 CustomSelect）
    ├── <script setup lang="ts" generic="T">  ← Vue 3.3+ 語法
    ├── const modelValue = defineModel<T>()
    └── defineProps<{ options: Array<{ label: string; value: T }> }>()
```
