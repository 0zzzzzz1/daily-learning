## 四、概念鞏固 — 用自己的話解釋

### Q：`inject(key)` 和 `inject(key, fallback)` 的差異？

**回答**：

差在 TypeScript 的回傳型別和執行期行為：

```ts
const theme = inject(themeKey)
// 型別：Theme | undefined
// 若上層沒有 provide，拿到 undefined
// → 後續使用 theme 時必須做 null check

const theme = inject(themeKey, { color: 'gray', size: 'sm' })
// 型別：Theme（確定，不是 undefined）
// 若上層沒有 provide，使用 fallback 值
// → 後續可以直接用 theme.color，不需要 null check
```

什麼時候必須提供 fallback？當元件**不能保證一定在 provide 的範圍內使用**時，就應提供 fallback（或至少做 null check），否則執行期會拿到 `undefined` 而出錯。

### Q：KeepAlive 的元件到底在「哪裡」？切走後 `setInterval` 還在跑嗎？

**回答**：

KeepAlive 的元件在切走後**保留在記憶體中**（DOM 從頁面移除，但 Vue 元件實例和狀態仍存在）。

`setInterval` **仍在跑**，這正是 `onDeactivated` 的用途：

```ts
let timer: ReturnType<typeof setInterval>

onMounted(() => {
  // 第一次進入：建立計時器
  timer = setInterval(updateChart, 1000)
})

onActivated(() => {
  // 切回來：重啟計時器（如果之前在 onDeactivated 裡停了）
  timer = setInterval(updateChart, 1000)
})

onDeactivated(() => {
  // 切走：暫停計時器，節省資源
  clearInterval(timer)
})

onUnmounted(() => {
  // KeepAlive 整體被銷毀時才觸發（換頁、父層消失）
  clearInterval(timer)
})
```

規律：`onMounted` 只在第一次；切走切回用 `activated` / `deactivated`；真正銷毀才觸發 `onUnmounted`。

## 五、今日知識地圖（文字樹狀圖）

```
W6 Day 1 — 元件彈性擴展三維度
│
├── provide / inject（跨層通訊）
│   ├── 問題：Props Drilling（跨多層傳遞繁瑣）
│   ├── 解法：provide 在祖先層，inject 在任意後代
│   ├── 型別安全：InjectionKey<T> = Symbol（不可偽造 + TS 推導）
│   │   └── injectionKeys.ts 集中管理所有 key
│   ├── inject 三情境
│   │   ├── inject(key)           → T | undefined（需 null check）
│   │   ├── inject(key, fallback) → T（安全）
│   │   └── inject(key)!          → T（危險，確定有值才用）
│   ├── provide reactive 物件 → 後代響應式更新
│   └── App-level provide（main.ts）→ 全域設定
│
├── Slots（元件內容彈性化）
│   ├── Default Slot：<slot />（fallback content 可選）
│   ├── Named Slots：<slot name="header" />
│   │   └── 父層：<template #header>...</template>
│   ├── Scoped Slots：<slot :item="item" />（資料與渲染分離）
│   │   └── 父層：<template #default="{ item }">...</template>
│   └── $slots.header → 條件渲染（避免空 DOM）
│
└── 動態元件 × KeepAlive（元件切換保留狀態）
    ├── <component :is="currentComponent" />
    │   └── :is 接受：元件物件 / 已註冊名稱 / AsyncComponent
    ├── KeepAlive
    │   ├── 機制：不銷毀 → 暫停（DOM 移除，實例保留）
    │   ├── onDeactivated → 切走時（暫停計時器、停監聽）
    │   ├── onActivated   → 切回時（重啟、刷新資料）
    │   └── include / exclude / max（LRU 精細控制）
    └── 設計決策：有狀態 Tab 用 KeepAlive；無狀態 Tab 不需要
```
